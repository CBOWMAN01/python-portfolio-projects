# My Python Portfolio

Welcome to my Python portfolio! This repository showcases **five beginner-to-intermediate Python projects**, each demonstrating different programming skills including GUI development, file handling, data management, and interactive applications.

---

## **Projects Included**

### 1. Enhanced Budget Tracker
- **Type:** GUI (Tkinter)  
- **Description:** Track your income and expenses with categories, view totals and balance, and save data using JSON.  
- **Skills:** GUI, JSON, loops, functions, data management  
- **Folder:** `Enhanced_Budget_Tracker`  

### 2. Enhanced To-Do List
- **Type:** GUI (Tkinter)  
- **Description:** Manage daily tasks with priorities, mark tasks as done/undone, and save them persistently with JSON.  
- **Skills:** GUI, lists, loops, JSON, interactive interface  
- **Folder:** `Enhanced_ToDo_List`  

### 3. Enhanced Random Quote Generator
- **Type:** GUI (Tkinter)  
- **Description:** Display random quotes by category, add new quotes, and save favorites using JSON.  
- **Skills:** GUI, lists, file handling, interactive interface  
- **Folder:** `Enhanced_Random_Quote_Generator`  

### 4. Python Quiz Game
- **Type:** Command-line  
- **Description:** Multiple-choice quiz game that asks questions, tracks score, and stores questions in JSON.  
- **Skills:** Loops, conditionals, functions, file handling (JSON)  
- **Folder:** `Python_Quiz_Game`  

### 5. Contact Book / Address Book
- **Type:** Command-line  
- **Description:** Add, view, search, and delete contacts with persistent storage in JSON.  
- **Skills:** Lists, loops, functions, file handling (JSON), data management  
- **Folder:** `Contact_Book`
