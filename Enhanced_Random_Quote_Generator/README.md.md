\# Enhanced Random Quote Generator



A beginner-friendly Python GUI application to display random quotes.



\## Features



\- Show random quotes from multiple categories

\- Add new quotes and categorize them

\- Save favorite quotes and view them later

\- Persistent storage using JSON

\- Interactive GUI with Tkinter



\## How to Run



1\. Open the folder in your terminal or IDE.

2\. Run the Python script:

```bash

python quote\_generator\_gui.py
