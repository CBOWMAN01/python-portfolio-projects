\# Enhanced To-Do List



A beginner-friendly Python GUI application to manage daily tasks.



\## Features



\- Add tasks with priority levels (High, Medium, Low)

\- Mark tasks as done or undone without deleting

\- Persistent storage using JSON

\- Interactive task list with GUI



\## How to Run



1\. Open the folder in your terminal or IDE.

2\. Run the Python script:

```bash

python todo\_list\_gui.py



Skills Demonstrated

* Python GUI with Tkinter
* File handling (JSON)
* Lists, loops, condtionals, and functions
* Interactive user interface
