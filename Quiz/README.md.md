\# Contact Book / Address Book



A simple command-line contact manager that lets you add, view, search, and delete contacts.



\## Features

\- Add, view, search, and delete contacts

\- Persistent storage using JSON

\- Command-line interface



\## How to Run

```bash

python contact\_book.py





\## Skills Demonstrated



* File handling (JSON)
* Lists, loops, and functions
* searching and updating records
